# DIKW

Data, information, knowledge, and wisdom for this research workspace.

| Level | Path | Role |
| --- | --- | --- |
| Data | `dikw/data/` | Raw or summarised experiment observations extracted later |
| Information | `dikw/information/` | Organised experiment context extracted later |
| Knowledge | `dikw/knowledge/` | Tested concepts, design specs, hypotheses, and claims |
| Wisdom | `dikw/wisdom/` | Accepted decision principles synthesised from knowledge |

Directory location alone does not accept a claim. Knowledge and wisdom still require evidence and executable support.
